# COS1020 - C++ Programming

Coursework from COS1020: C++ Programming at the American University in Bulgaria (AUBG).

## Overview

This repository contains exercises, labs, and homework assignments covering fundamental to advanced C++ programming concepts.

## Repository Structure

### Core Topics

- **01. Intro to C++ Programming** - Basic syntax, input/output stream
- **02. Fundamental Data Types** - Variables, constants, and type conversions
- **03. Decision Statements** - If statements and switch cases
- **04. Loops** - For loops, while/do-while loops
- **05. Functions** - Function declarations, parameters, and return values
- **06. Simple Data Types** - Chars and enums
- **07. Arrays and Structs** - Arrays (single- and multidimensional) and structs
- **08. Strings** - C-style strings and string manipulation
- **09. Recursion** - Recursive algorithms and functions
- **10. Streams and Files** - File I/O and stream operations
- **11. Pointers** - Memory addresses and pointers

### Object-Oriented Programming

- **12. Intro to OOP** - Classes, objects, encapsulation
- **13. Inheritance and Polymorphism** - Class hierarchies, abstraction, and virtual functions
- **14. Templates** - Generic template functions
- **15. Operator Overloading** - Custom operators for classes

### Assignments

- **00. Homeworks** - Major homework assignments (4 total)


## Notes

Each topic folder contains:
- `.pptx` - lecture slides and exercises that have been implemented
- `.cpp` - source files with the exercises' implementations
